# OWASP Top 10 (2021) grid

Each risk, what this repo does about it, + where to look. Where something doesn't apply I say so instead of pretending.

| #   | Risk                          | What's done                                                                                                                                                                                                                                                               | Where                                                                                                          |
| --- | ----------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------- |
| A01 | Broken access control         | RBAC, deny by default, 1 policy file. Every use case checks the caller's role before doing anything, not the route. Denied calls go to an audit log. MCP callers get visitor rights only                                                                                  | `src/core/domain/access/rbac.ts`, `src/core/application/app.ts`, `src/core/application/use-cases/authorize.ts` |
| A02 | Cryptographic failures        | Sessions signed with HMAC-SHA256 (Web Crypto), constant time verify. Access codes compared with `timingSafeEqual` on sha256 digests. Cookies `HttpOnly`, `SameSite=Lax`, `Secure` in prod. Webhooks signed with a timestamp inside the HMAC                               | `src/adapters/driven/security/*`, `src/adapters/driven/events/signing.ts`                                      |
| A03 | Injection                     | Every input goes through Zod first (bodies, env, localStorage, PokéAPI responses, the AI's answer). Path params must match `^[a-z0-9-]{1,40}$` before they touch an upstream url. No SQL in this repo                                                                     | `src/adapters/driving/http/http-api.ts`, `src/adapters/driven/pokeapi/pokeapi-catalog.ts`                      |
| A04 | Insecure design               | Hexagonal core: rules can't be skipped by a new entry point, bcs the check lives in the use case. Threats written down in ADR 0002                                                                                                                                        | `docs/adr/0002-rbac-and-sessions.md`                                                                           |
| A05 | Security misconfiguration     | Env parsed with Zod at boot, bad config = crash with a clear message. Roles with no code configured can't be reached (fail closed). Security headers on every route, `x-powered-by` off, container runs as non root                                                       | `src/composition/server.ts`, `next.config.mjs`, `Dockerfile`                                                   |
| A06 | Vulnerable components         | Lockfile + `npm ci` everywhere. Go + Python services use the standard library only                                                                                                                                                                                        | `package-lock.json`, `services/*`                                                                              |
| A07 | Auth failures                 | Login rate limited per client (5/min), JSON only (no cross site form posts). Expired or tampered cookie = visitor again + cookie dropped. Keycloak tokens: issuer, audience, expiry checked, RS256/ES256 only (no HS256 with the public key trick, there's a test for it) | `src/core/application/use-cases/sessions.ts`, `src/adapters/driven/security/oidc-token-verifier.ts`            |
| A08 | Software + data integrity     | CI checks the generated SDK matches the OpenAPI spec. Outbound webhooks are signed so receivers can check integrity. The AI's output is validated before anyone sees it                                                                                                   | `.github/workflows/ci.yml`, `src/sdk/contract.test.ts`                                                         |
| A09 | Logging + monitoring failures | 1 JSON log line per request with a request id + trace id, OpenTelemetry spans, audit log for access decisions, Prometheus metrics on the Go gateway                                                                                                                       | `src/adapters/driven/logging`, `src/instrumentation.ts`, `services/telemetry-gateway`                          |
| A10 | SSRF                          | The server only calls fixed hosts (PokéAPI, Anthropic, Slack/webhook urls from env). User input never becomes a host, only a validated path segment                                                                                                                       | `src/adapters/driven/pokeapi/pokeapi-catalog.ts`                                                               |
